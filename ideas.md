## Idea 1: Academic Notebook — Warm Paper Brutalism
**Design Movement:** Neo-Brutalism meets analog stationery aesthetic
**Core Principles:**
- Ruled-paper texture backgrounds with ink-like borders
- Heavy, expressive typography contrasted with handwritten-style accents
- Color-coded course tabs like physical tabbed notebooks
- Deliberate imperfection: slight rotations, torn-edge dividers

**Color Philosophy:**
- Cream/ivory base (#F5F0E8) evoking aged paper
- Deep navy ink (#1A2744) for primary text
- Highlighter accents: yellow (#FFE566), coral (#FF6B6B), mint (#6BFFB8)
- Each semester folder gets a distinct highlighter color

**Layout Paradigm:**
- Left sidebar as a tabbed binder spine
- Main area as a ruled notebook page
- Calendar rendered as a physical month-view grid with handwritten-style numbers

**Signature Elements:**
- Dashed ruled lines on content areas
- Sticky-note style assignment cards
- Checkbox checkmarks that look hand-drawn

**Interaction Philosophy:**
- Completing an assignment "crosses it off" with an animated ink stroke
- Folders open with a page-flip animation
- Hover states add a subtle paper lift shadow

**Animation:**
- Ink-draw SVG stroke animations for completion
- Slide-in from left for sidebar navigation
- Soft bounce for new item creation

**Typography System:**
- Display: Playfair Display (serif, authoritative)
- Body: DM Sans (clean, readable)
- Accent: Caveat (handwritten feel for labels/dates)
</text>

## Idea 2: Minimal Productivity OS — Dark Command Center
**Design Movement:** Cyberpunk-lite meets macOS dark mode productivity
**Core Principles:**
- Dark slate base with neon accent pops
- Monospace font for data/dates, humanist sans for content
- Dense information hierarchy with clear visual lanes
- Glass-morphism panels with subtle blur

**Color Philosophy:**
- Deep charcoal base (#0F1117)
- Electric indigo accent (#6366F1)
- Neon green for completed states (#22C55E)
- Amber for warnings/deadlines (#F59E0B)

**Layout Paradigm:**
- Three-column layout: semester nav | course list | detail/calendar
- Resizable panels
- Calendar as a compact side widget

**Signature Elements:**
- Glowing border on active items
- Terminal-style semester folder labels
- Progress bars for course completion

**Interaction Philosophy:**
- Keyboard-first navigation
- Completion triggers a satisfying "zap" animation
- Drag-and-drop assignment reordering

**Animation:**
- Fade + scale for panel transitions
- Strikethrough animation with neon glow on completion
- Pulse animation on upcoming deadlines

**Typography System:**
- Display: Space Grotesk (geometric, modern)
- Mono: JetBrains Mono (dates, codes)
- Body: Inter (neutral, readable)

## Idea 3: Soft Academic — Warm Pastel Collegiate
**Design Movement:** Contemporary collegiate meets Notion-style calm productivity
**Core Principles:**
- Warm off-white base with dusty pastel accents
- Generous whitespace with card-based content blocks
- Soft shadows and rounded corners for approachability
- Color-coded semester folders with pastel hues

**Color Philosophy:**
- Warm white base (#FAFAF8)
- Dusty rose primary (#C4748A)
- Sage green secondary (#7BA68A)
- Soft amber for lifestyle (#D4A853)
- Each course gets a unique pastel color chip

**Layout Paradigm:**
- Left sidebar for semester/course navigation (240px fixed)
- Main content area split: assignment list (top 60%) + calendar (bottom 40%)
- Or toggle between list view and full calendar view

**Signature Elements:**
- Pill-shaped course color tags
- Soft card shadows with hover lift
- Month calendar with dot indicators for assignments

**Interaction Philosophy:**
- Smooth, calm transitions — nothing jarring
- Completion crosses off with a satisfying strikethrough + fade
- Lifestyle habits shown as daily streak dots

**Animation:**
- Gentle slide-in for new items
- Strikethrough + opacity fade for completed assignments
- Calendar day cells pulse softly when assignments are due

**Typography System:**
- Display: Fraunces (warm serif for headings)
- Body: Plus Jakarta Sans (clean, modern)
- Labels: DM Mono (dates, course codes)
